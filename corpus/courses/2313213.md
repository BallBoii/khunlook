## Description
Types of digital camera; basic elements of digital camera; image size and file type; photographic setting; exposure control; composition; various types of photographic techniques; image editing; image presentation techniques.

## คำอธิบายรายวิชา
ประเภทของกล้องดิจิทัล องค์ประกอบพื้นฐานของกล้องดิจิทัล ขนาดของภาพและประเภทของไฟล์ภาพ การปรับตั้งค่าในการถ่ายภาพ การควบคุมการเปิดรับแสง การจัดองค์ประกอบ เทคนิคการถ่ายภาพแบบต่างๆ การตกแต่งภาพ เทคนิคการนำเสนอภาพ
