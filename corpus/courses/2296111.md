## Description
Definition, scope, characteristics and importance of creative learning spaces; types of creative learning spaces; information resources, services and access provided by each type of creative learning spaces using creative learning spaces for lifelong learning.

## คำอธิบายรายวิชา
ความหมาย ขอบเขต ลักษณะ และความสำคัญของแหล่งเรียนรู้เชิงสร้างสรรค์ ประเภทของแหล่งเรียนรู้ เชิงสร้างสรรค์ ทรัพยากรสารสนเทศ บริการ และการเข้าถึงสารสนเทศในแหล่งเรียนรู้เชิงสร้างสรรค์แต่ละประเภท การใช้แหล่งเรียนรู้เชิงสร้างสรรค์เพื่อการเรียนรู้ตลอดชีวิต
